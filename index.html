tadanoit-sns について

tadanoit-sns は、「ただのIT社員」の運営者が自分のアカウントの運用だけに使う個人用ツールです。 一般のユーザーがログインしたり使ったりする機能はありません。

  • 運営者が作ったショート動画を、運営者の YouTube チャンネル（@tadanoIT）にアップロードする
  • YouTube で公開されている動画の傾向（タイトル・再生回数など）を調べ、動画づくりの参考にする
  • 運営者のチャンネルに届いたコメントを読み、返信する

このツールは YouTube API サービス を利用しています。
