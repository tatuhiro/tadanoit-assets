tadanoit-sns プライバシーポリシー

制定・最終改定: 2026年11月6日

1. このツールについて

「tadanoit-sns」（以下「本ツール」）は、「ただのIT社員」の運営者（以下「運営者」）が、 自分の YouTube チャンネル（@tadanoIT）の運用のためだけに使う個人用ツールです。 本ツールは YouTube API サービスを利用しています。

2. 利用する権限と取得する情報

本ツールは、運営者本人の Google アカウントで次の権限を取得します。

  • youtube.upload：運営者の動画を運営者のチャンネルにアップロードするため
  • youtube.force-ssl：公開動画の検索、運営者のチャンネルのコメントの読み取りと返信のため

取得する情報

  • 運営者のチャンネルの ID
  • YouTube で公開されている動画の情報（タイトル、チャンネル名、再生回数、高評価数、コメント数、長さ、サムネイル）
  • 運営者のチャンネルに投稿された公開コメント（コメント本文、投稿者の表示名、コメント ID、投稿日時）

運営者以外の方の Google アカウントにログインしたり、非公開の情報を取得したりすることはありません。

3. 情報の使い方

  • 公開動画の情報は、その日の動画づくりの参考（どんなテーマや見せ方が見られているか）にだけ使います
  • コメントは、返信するかどうかの判断と返信文の作成にだけ使います
  • テーマ選びと、返信の判断・返信文の作成のため、公開動画の情報（サムネイルを含む）とコメント本文を Anthropic 社の AI（Claude API）に送って処理します。 Anthropic 社の取り扱いは Anthropic のプライバシーポリシー をご覧ください
  • 情報を販売したり、広告やその他の目的で第三者に提供したりすることはありません

4. 保存と削除

  • 認証情報（リフレッシュトークン）は、暗号化された保管場所（GitHub Secrets）にのみ保存します
  • 公開動画の情報は処理中にだけ使い、保存しません（保存するのは件数だけです）
  • コメント本文と投稿者の表示名は保存しません。二重返信を防ぐため、コメント ID と対応の記録だけを保存し、30日を過ぎたものは自動で削除します
  • 削除のご依頼は、下記のお問い合わせ先からご連絡ください。確認のうえ速やかに削除します

5. 利用しているサービスと権限の取り消し

  • YouTube 利用規約
  • Google プライバシーポリシー
  • 本ツールへの権限は、Google アカウントの セキュリティ設定のページからいつでも取り消せます

6. Cookie など

本ツールと本サイトは、Cookie や類似の技術で閲覧者の情報を保存・取得しません。

7. お問い合わせと改定

お問い合わせは note のクリエイターページのお問い合わせ機能からご連絡ください。 本ポリシーを改定するときは、このページで最終改定日とともにお知らせします。

1. About this tool

"tadanoit-sns" (the "Tool") is a personal tool used only by the operator of "ただのIT社員" (the "Operator") to run the Operator's own YouTube channel (@tadanoIT). The Tool uses YouTube API Services.

2. Scopes and data accessed

The Tool is authorized only with the Operator's own Google account, with these scopes:

  • youtube.upload: to upload the Operator's videos to the Operator's channel
  • youtube.force-ssl: to search public videos, and to read and reply to comments on the Operator's channel

Data accessed:

  • The Operator's channel ID
  • Information about public YouTube videos (title, channel name, view/like/comment counts, duration, thumbnail)
  • Public comments posted on the Operator's channel (comment text, author display name, comment ID, publish time)

The Tool never signs in to anyone else's Google account and never accesses private data of other users.

3. How data is used

  • Public video information is used only as a reference for the day's video planning (which topics and formats people watch)
  • Comments are used only to decide whether to reply and to draft the reply
  • For topic selection and reply drafting, public video information (including thumbnails) and comment text are sent to Anthropic's AI (Claude API) for processing. See Anthropic's Privacy Policy
  • Data is never sold or shared with third parties for advertising or any other purpose

4. Storage and deletion

  • The OAuth refresh token is stored only in an encrypted secret store (GitHub Secrets)
  • Public video information is used only during processing and is not stored (only the number of results is recorded)
  • Comment text and author names are not stored. Only comment IDs and the action taken are kept to prevent duplicate replies, and they are deleted automatically after 30 days
  • To request deletion, contact us using the contact method below; we will delete the data promptly after confirmation

5. Services used and revoking access

  • By using this Tool you are also bound by the YouTube Terms of Service
  • Google Privacy Policy
  • You can revoke the Tool's access at any time from the Google security settings page

6. Cookies

Neither the Tool nor this website stores or reads visitors' information with cookies or similar technologies.

7. Contact and changes

Contact us through the contact feature on our note creator page. Any changes to this policy will be posted on this page with the updated date.
